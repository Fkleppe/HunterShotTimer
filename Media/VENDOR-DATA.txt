Ammo vendor data (VendorData.lua)

VendorData.lua is generated by tools/build_vendors.py from:

- Wowhead Classic "Sold by" lists: which NPCs sell each item (checked against both databases below).

- pfQuest database (https://github.com/shagu/pfQuest): which NPCs sell each item (cross-check),
  NPC names, spawn coordinates and faction.
